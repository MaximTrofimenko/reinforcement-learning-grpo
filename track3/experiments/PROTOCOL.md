# Новый цикл экспериментов

До первой оценки модели фиксируются файлы данных, seed и все настройки в
`2026-11-18/protocol.json`. Там же записаны SHA-256 исходного кода и данных.
Протокол и выборки сохраняются отдельным Git-коммитом до запуска.

Используется Qwen3-0.6B, тот же промпт и та же проверка ответа.
Теперь исходные числа могут повторяться. Например, в задаче с числами
`3, 3, 5` нужно использовать две тройки и одну пятёрку.
Диапазон чисел: 2–12, цели: 5–60. В генераторе те же четыре шаблона решений:
`a+b+c`, `a*b+c`, `a*b-c`, `(a+b)*c`. Решение в файл задачи не записывается.

Итоговые 220 задач выбраны с seed `20261118` из задач, которых нет ни в одной
старой выборке. Затем из оставшихся задач выбраны 400 учебных и 50 проверочных.
Все три новые выборки не пересекаются. Учебные и проверочные задачи могут
совпадать с задачами старого исследования. Из-за исключения старых задач
итоговая выборка чаще содержит повторяющиеся числа. Это ограничение будет
указано в отчёте; сравнение всех моделей проводится на одних задачах.

Seed обучения: `20261118`, `20261119`, `20261120`. Для каждого seed выполняются
два запуска с KL `0,02` и `0`. В каждом — 200 шагов, четыре ответа на шаг,
скорость обучения `5e-5`, LoRA `r=8`, `alpha=16`, dropout `0`.
Остальные настройки совпадают. Длинные рассуждения отключены.

Сначала оценивается исходная модель на 220 итоговых задачах. Если её точность
не попала в диапазон 10–50%, скрипт останавливается до обучения. Новую сложность
в таком случае нужно фиксировать в новом протоколе, сохранив неудачную проверку.

Затем запускаются все шесть обучений. Промежуточная оценка выполняется только
на 50 проверочных задачах. Используются адаптеры после 200 шагов; лучший
чекпойнт не выбирается. После завершения всех обучений адаптеры оцениваются
на итоговых задачах с жадным декодированием: `do_sample=False`, `num_beams=1`,
максимум 64 новых токена. Основная метрика — доля точных решений.
Для обученных вариантов считаются среднее и выборочное стандартное отклонение
по трём seed, а также парная разница между условиями. Гиперпараметры по
итоговым ответам не меняются.

`run_experiment.py` проверяет хеши и записывает начало и конец каждого этапа
в `results/run_journal.jsonl`. Существующие результаты не перезаписываются.
Чтобы повторить расчёт в новой папке, из `track3` нужно выполнить:

```bash
python run_experiment.py --output-dir rerun/2026-11-18
```
